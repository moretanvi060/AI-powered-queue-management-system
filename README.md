# AI-Powered Smart Queue Management System

🚀 **Live Demo:** https://ai-smart-queue.onrender.com

## 📌 About the Project

The AI-Powered Smart Queue Management System is a web-based system designed to reduce waiting time and improve queue management for organizations such as hospitals, clinics, salons, service centers, restaurants, and educational institutions.

Instead of waiting physically in a queue, customers can join a queue digitally, receive a token, view their queue status, and get an estimated waiting time.

## 🤖 AI Features

- AI-based waiting-time prediction
- Dynamic queue optimization
- Priority-based smart routing
- AI-assisted crowd and queue monitoring
- Smart Arrival with traffic estimation
- AI-powered queue insights

## ✨ Key Features

- Digital token generation
- Live queue status
- Priority customer handling
- Admin/operator dashboard
- Counter management
- Serve and Skip controls
- Smart Arrival recommendations
- Customer assistance chatbot

## 📂 Project Structure

- `app.py` – Main Flask application and routes
- `ai_engine.py` – AI-based queue prediction and optimization logic
- `db.py` – Database setup and queue data management
- `config.py` – Application configuration
- `traffic_service.py` – Smart Arrival traffic estimation
- `templates/` – HTML pages
- `static/` – CSS, JavaScript and static assets
- `requirements.txt` – Python dependencies
